- 风格：v8 激进（立直/放铳最高、立直后和率最低）；joint 防守最稳+转化1位最好；community 副露最多、立直最少、略弱。

## gpu-16 部署（踩坑实录 → CLAUDE.md「服务器环境铁律」）
gpu-16 = root@8.139.242.0，62G RAM / 32 核 / RTX5880-Ada-16Q。原有 Mortal3 + joint 资产 + `~/aigc_apps/venv`(py3.12/torch2.8/pip25)，无 riichienv/Rust/uv。
- **本地↔gpu-16 链路极慢**(~30kB/s)：community(273M)+v8(101M) 权重打包成 tar **让用户传**（直传要几小时）。gpu-16 自己外网快（cargo 走 rsproxy.cn 秒下）。
- **血泪坑（耗时主因，全是装坏静默挂死，非算得慢）**：① 我图省事用 `python3.10 -m venv` 建**空白 venv** 编译 riichienv；② repo `rust-toolchain.toml` 钉 1.92，最初装工具链时（链路抽风）只装一半 + 一个 `rustc -vV` 死锁占 rustup 锁 → maturin 干坐 36min 0% CPU；③ 空白 venv 老 pip(22.0.2) 不认 maturin `--group`；④ `pip install -U pip` 从 aliyun 镜像装坏 pip。
- **正解（用户纠正：用 aigc 3.12 真环境，别和空白 python3.10 较劲）**：riichienv 装进 `~/aigc_apps/venv`：`PATH=$HOME/.cargo/bin:$PATH RUSTUP_TOOLCHAIN=stable ~/aigc_apps/venv/bin/maturin build --release -i ~/aigc_apps/venv/bin/python`（stable 绕坏的1.92；-i 出 cp312 wheel）→ `pip install <cp312 wheel>`（普通 install 避 --group、不动 aigc pip）。父进程+三引擎同住 aigc 3.12（`ARENA_ENGINE_PY`、模块名互不冲突）。**已写入 CLAUDE.md + 记忆 `use-aigc-venv-not-blank-python`，注明同适用 Mortal/Mortal3/autoplay/learnrust/zeroppo。**
- 可移植改动（commit `b0058d6`）：registry 引擎 python 经 `ARENA_ENGINE_PY` 覆盖；stat_report Mortal3 路径经 `ARENA_MORTAL3` 覆盖；riichienv 置于 `~`（与 `~/Mortal3` 同级）则 `MORTAL3=../Mortal3`、`_pkgs/` 相对路径自洽。
